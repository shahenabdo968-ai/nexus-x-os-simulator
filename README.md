# NEXUS-X SOVEREIGN OS

### Operating System Concepts Simulator | Python · PyQt5

An educational desktop simulator demonstrating fundamental Operating System concepts through a graphical interface.

## Features

- CPU scheduling with Multilevel Feedback Queue (MLFQ).
- Memory management: First Fit, Best Fit, and Worst Fit.
- Simulated file system with file and directory operations.
- I/O device simulation and request queues.
- Process management and scheduling visualization.
- Memory visualization and CPU scheduling timelines.
- Banker's Algorithm demonstration.
- Login interface.

## Technology Stack

- Python
- PyQt5
- Matplotlib

## Requirements

- Python 3.10 or newer
- Dependencies listed in `requirements.txt`

## Installation

Clone the repository, then enter its directory.

Create and activate a virtual environment:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
py -m pip install -r requirements.txt
```

## Run the Application

```powershell
py main.py
```
